This repository is a (not yet well documented) collection of code 
that creates simple examples plots for the SSAM optimisation objective 
for Gradient Descent and the ODE method. 
The settings and run configurations can all be set in main.py,
the necessary utilities are in utils.py. The remaining stuff 
is code for additional experiments. This code can directly 
replicate the plots provided in the thesis, the folders currently contain a plethora of 
different examples that have not made it in the final version 
and should therefore be interepreted with a grain of salt.
